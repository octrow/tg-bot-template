# 0004. Только OpenRouter, без запасного провайдера

Дата: 2026-10-07. Статус: принято. Частично заменяет ADR-0003 (ступень прямого OpenAI). Унаследовано из исходного бота.

## Контекст

По ADR-0003 лестница моделей заканчивалась прямым OpenAI на случай, когда лежит сам OpenRouter. Прямой OpenAI и Claude признаны устаревшими, на проде ступень OpenAI уже не работала: ключа для неё не было.

## Решение

Бот обращается к LLM только через OpenRouter. От отказа одной модели защищают запасные модели того же провайдера (лестница по времени, ADR-0003). Запасного провайдера нет. Ступень OpenAI и выбор провайдера удалены.

## Последствия

- Если лежит сам OpenRouter, бот отвечает отказом. Это принятый риск.
- Значение `TGBOT_LLM_PROVIDER`, отличное от `openrouter` (например, прежние `openai` или `claude`), роняет старт, а не молча игнорируется.
- Один ключ (`OPENROUTER_API_KEY`) и один путь вызова. Меньше кода и тестов.

## Дополнение 2026-10-08: OmniRoute вместо OpenRouter

`TGBOT_LLM_PROVIDER=omniroute` направляет все вызовы в свой шлюз OmniRoute (OpenAI-совместимый, `/v1/chat/completions` и `/v1/responses`). Это замена, а не запасной провайдер: ступень по-прежнему одна. Поля, которые понимает только OpenRouter (`provider.quantizations`, `models`, `/generation`), шлюзу не шлются; запасные модели скриншотов и выбор хостера переносятся на сторону шлюза (combo).
