## ADDED Requirements

### Requirement: Режим "только для админов"
Копия бота для одного человека SHALL включать режим "только для админов" настройкой `TGBOT_OWNER_ONLY=1`. В этом режиме бот SHALL пускать только пользователей из `ADMIN_USER_IDS`: записи allowlist не дают доступа, остальным бот SHALL NOT отвечать даже отказом, событие отказа в журнал пишется как обычно. `/whoami` SHALL работать по-прежнему: им узнают свой `user_id`. Режим с пустым `ADMIN_USER_IDS` SHALL ронять старт с ошибкой конфигурации: иначе ботом не смог бы пользоваться никто.

#### Scenario: Админ пишет в режиме "только для админов"
- **WHEN** режим включён, и пользователь из `ADMIN_USER_IDS` задаёт вопрос
- **THEN** бот отвечает как обычно

#### Scenario: Пользователь из allowlist в режиме "только для админов"
- **WHEN** режим включён, и пользователь из allowlist, но не из `ADMIN_USER_IDS`, отправляет сообщение
- **THEN** бот не отвечает, в журнале есть событие отказа

#### Scenario: Режим без админов
- **WHEN** `TGBOT_OWNER_ONLY=1`, а `ADMIN_USER_IDS` пуст
- **THEN** старт падает с ошибкой конфигурации, называющей `ADMIN_USER_IDS`
