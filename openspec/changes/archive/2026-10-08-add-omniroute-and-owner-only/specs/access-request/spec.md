## MODIFIED Requirements

### Requirement: /request_access работает до проверки доступа

Команда `/request_access` SHALL быть доступна любому пользователю в личном чате, включая тех, кого нет в allowlist, - вторая и последняя такая команда наряду с `/whoami`. Пользователю, который уже в allowlist (или админу), команда SHALL отвечать, что доступ уже есть, и заявку не создавать. В режиме "только для админов" (`access-control`) команда SHALL молчать: заявка не создаётся, админам ничего не уходит.

#### Scenario: Неизвестный пользователь отправляет /request_access
- **WHEN** пользователь не из allowlist отправляет `/request_access` в личке
- **THEN** бот начинает оформление заявки (спрашивает ФИО и причину), а не отвечает отказом

#### Scenario: Разрешённый пользователь отправляет /request_access
- **WHEN** пользователь из allowlist отправляет `/request_access`
- **THEN** бот отвечает, что доступ уже есть; заявка не создаётся, админам ничего не уходит

#### Scenario: /request_access в режиме "только для админов"
- **WHEN** включён режим "только для админов", и кто угодно отправляет `/request_access`
- **THEN** бот не отвечает, заявка не создаётся, админам ничего не уходит
