# html-send-fallback Specification

## Purpose
Бот отправляет сообщения с разметкой и умеет откатиться на текст без тегов, если
разметка оказалась невалидной. Эта capability задаёт границы отката: он лечит
только ошибку разбора разметки и никогда не превращает один ответ бота в два
сообщения в чате.

## Requirements

### Requirement: Повторная отправка без разметки только при ошибке разбора

Бот SHALL повторять отправку сообщения без разметки только тогда, когда Bot API
отверг сообщение из-за невалидной разметки. При любой другой ошибке отправки
(таймаут, сетевой сбой, требование подождать перед следующим запросом,
недостаточные права, заблокированный чат, слишком длинный текст) повторная
отправка того же текста SHALL NOT выполняться. Если текст отправляется частями,
правило действует для каждой части отдельно: откат без тегов затрагивает только
ту часть, которую отверг Bot API.

#### Scenario: Невалидная разметка

- **WHEN** Bot API отвергает сообщение с ошибкой разбора разметки
- **THEN** бот отправляет тот же текст без тегов разметки, с той же клавиатурой
- **AND** в чате оказывается ровно одно сообщение

#### Scenario: Таймаут при уже принятом сообщении

- **WHEN** отправка завершается таймаутом или сетевой ошибкой
- **THEN** бот SHALL NOT отправлять этот текст повторно
- **AND** в чате SHALL NOT появляться второй, неформатированный экземпляр того же
  сообщения

#### Scenario: Ограничение частоты запросов

- **WHEN** Bot API отвечает требованием подождать перед следующим запросом
- **THEN** бот SHALL NOT трактовать это как ошибку разметки и SHALL NOT слать
  текст без тегов

#### Scenario: Отказ по длине не считается ошибкой разметки

- **WHEN** Bot API отвергает сообщение, потому что текст слишком длинный
- **THEN** бот SHALL NOT повторять тот же текст без тегов
- **AND** текст доставляется частями по правилам `long-message-send`

#### Scenario: Невалидная разметка в одной из частей

- **WHEN** длинный текст отправляется частями и Bot API отвергает разметку второй части
- **THEN** без тегов повторно уходит только вторая часть
- **AND** первая часть не дублируется

### Requirement: Правило распространяется на все сообщения бота

Правило отката SHALL действовать одинаково для всех сообщений, которые бот
отправляет пользователю, а не только для уточняющих вопросов.

#### Scenario: Любое сообщение с разметкой

- **WHEN** бот отправляет вопрос по полю, резюме, уточняющий вопрос или
  служебное сообщение с разметкой и получает ошибку не про разбор разметки
- **THEN** повторная отправка не выполняется в любом из этих случаев
