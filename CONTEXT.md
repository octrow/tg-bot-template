# CONTEXT

Глоссарий шаблона tg-bot. Только термины, без деталей реализации.

| Термин | Значение |
|---|---|
| **Режим** | То, что бот сейчас делает с обычным текстом пользователя. В шаблоне режимов два: **Справка** (по умолчанию) и **Эхо** (демо). В каждый момент активен ровно один. Название режима одно и то же везде, где его видит пользователь. _Избегать_: трек, флоу. |
| **Реестр режимов** | Список режимов кроме Справки. Из него бот узнаёт о режиме всё, что нужно снаружи: команду входа, кнопки, место в меню, метку для классификатора намерения. Режим появляется в боте, только когда попадает в реестр. |
| **Сессия режима** | Время, пока пользователь находится в режиме кроме Справки. Открывается входом в режим (командой или кнопкой перехода), закрывается выходом в Справку или входом в другой режим. Пока сессия открыта, обычный текст идёт этому режиму, а не Справке. У пользователя не больше одной открытой сессии режима. |
| **Шапка режима** | Первая строка каждого сообщения режима: значок, название режима и, если есть, этап (`🔁 Эхо · шаг 2`). Значок режима стоит только здесь: в тексте, на кнопках и в меню режим называется словами без значка. _Избегать_: заголовок, хедер. |
| **Справка** | Режим по умолчанию: ответ на вопрос обычным текстом, простым языком. Опирается на документацию и код продукта, которые боту дали читать. Если по смыслу нужен другой режим, под ответом появляется кнопка перехода, но сама Справка никуда не переходит. Непонятный ответ можно попросить объяснить проще, а после второй попытки передать вопрос людям Отзывом. |
| **Эхо** | Демо-режим шаблона: повторяет текст пользователя и считает шаги. Это образец нового режима и проверка, что механика режимов работает. В настоящем боте его убирают, когда появляется первый свой режим. |
| **Пачка сообщений** | Одно или несколько сообщений пользователя подряд (текст, подписи, распознанные скриншоты), на которые бот отвечает одним ответом. Пачка закрывается паузой. Пока распознаётся скриншот, пачка остаётся открытой. Сообщения, пришедшие, пока ответ уже готовится, в пачку не входят: это **поздние сообщения**. Ответ всё равно уходит сразу, с пометкой, на каких сообщениях он основан, и кнопкой пересчёта. Пересчёт учитывает пачку, поздние сообщения и сам первый ответ. Это не повторная попытка Справки. Если кнопку не нажали, поздние сообщения входят в следующую пачку. Команда отбрасывает открытую пачку, и бот коротко говорит, что предыдущее сообщение не обработано. Кнопки под старыми ответами пачку не трогают. |
| **Распознанный скриншот** | Текст, который бот один раз получает из присланной картинки: весь видимый текст дословно (идентификаторы символ в символ), что это за экран и что пользователь выделил стрелками или рамками. Дальше сообщение обрабатывается по подписи и этому тексту, сама картинка не хранится. Пользователю этот текст не показывается, в журнал попадает. |
| **Лестница моделей** | Порядок, в котором к вызову подключаются модели, пока пользователь ждёт ответа: следующая подключается по времени или после брака предыдущей, первый ответ, прошедший проверки, отменяет остальные. Все модели лестницы - от одного провайдера (OpenRouter), запасного провайдера нет. |
| **Запасная модель** | Любая модель лестницы, кроме основной. Синоним "дублёр" не используется. |
| **Выродившийся ответ** | Ответ модели, распавшийся в бессвязный текст: обрывки слов, смешение алфавитов внутри слов, символы чужих письменностей. Пользователю не показывается и не кэшируется. Не то же самое, что непроверенный ответ: тот связный, но не подтверждён источниками. |
| **Непроверенный ответ** | Ответ модели на полный вызов (инструменты чтения были предложены), в котором модель ни разу не обратилась к файлам: ни чтением, ни поиском. Пользователь видит его с пометкой, что подтверждения нет. Такой ответ не кэшируется и считается в `/cost`. |
| **Отзыв** | Сообщение пользователя о работе бота, отправленное через `/support`. Привязан к последней сессии пользователя на момент отправки (или ни к какой, если сессий не было). Отзывом становится и вопрос, который Справка не смогла объяснить после повторного ответа и пользователь передал людям: вместе с вопросом приходят обе попытки ответа, и видно, что это вопрос, а не жалоба. Отзывом становится и сообщение о сбое, которое пользователь отправил кнопкой под ошибкой: вместе с ним приходит код инцидента. |
| **Код инцидента** | Короткий номер записи журнала, который пользователь видит в сообщении о сбое вместо технических подробностей. Его можно переслать в `/support`, по нему разработчик находит всё остальное. |
| **Непрочитанный отзыв** | Отзыв, который ни один админ ещё не пометил прочитанным. "Прочитано" - общий статус: закрыл один админ - закрыт для всех. Ставится только явным действием, просмотр списка статус не меняет. |
| **Напоминание об отзывах** | Сообщение всем админам о числе непрочитанных отзывов. Уходит по рабочим дням в фиксированный час; при нуле непрочитанных не отправляется. |
| **Заявка на доступ** | Запрос чужого пользователя на попадание в allowlist через `/request_access`. Содержит автособранный профиль и историю контактов, по желанию ФИО и причину. У пользователя не больше одной активной заявки; решает первый нажавший админ, заявитель узнаёт о любом исходе. |
| **Язык пользователя** | Русский или английский; действует на все тексты, адресованные этому пользователю, включая ответы модели. Хранится за пользователем, до первого явного выбора определяется по профилю Telegram. Сообщение всегда на языке получателя, а не отправителя. Текст самого пользователя (вопрос, ФИО, отзыв) не переводится. |
| **Простой язык** | Мерка для всех текстов бота, которые читает человек: ответы Справки, статичные тексты, кнопки. Читатель - нетехнический пользователь: не больше 5 строк подряд, суть первой строкой, без путей, имён функций и воды. Правила и примеры: `docs/simple-language.md`. |
